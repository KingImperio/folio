# Folio

A GitHub profile README generator with live preview, markdown output, and local persistence.

## What it does

Folio is a two-panel editor that generates clean, valid GitHub-flavored markdown for profile READMEs. The left panel is a form with sections for header, skills, GitHub stats, projects, and contact links. The right panel shows a live preview of the rendered README as it would appear on GitHub. Users can copy the markdown to clipboard or download it as README.md. All form state persists in localStorage.

## Tech

- HTML / CSS / JavaScript (Vanilla)
- Satoshi font from Fontshare CDN for UI
- Recoleta font from Fontshare for form section labels
- JetBrains Mono from Google Fonts for markdown output
- Custom lightweight markdown parser

## Run locally

Download or clone the repo. Open index.html in a browser. No build step required.
